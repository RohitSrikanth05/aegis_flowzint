# Aegis Flowzint

This repository contains the frontend for Aegis Flowzint in the `front-end/` folder. It is a TanStack Start app built with React, Vite, TypeScript, Tailwind CSS, and Radix/shadcn-style UI components.

## Frontend

The frontend provides the main product UI, including the chat, cockpit, and supporting dashboard components under `front-end/src/`.

## Run It

From the `front-end/` directory:

```bash
npm install
npm run dev
```

Other useful commands:

```bash
npm run build
npm run preview
npm run lint
npm run format
```

If you prefer Bun, install it first and then use the matching commands:

```bash
bun install
bun dev
```
